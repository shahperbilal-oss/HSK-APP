# HSK Learning Web Application

A full-stack web application built with **Python and Django** to help students practice HSK vocabulary.

## Features
* Flashcards for vocabulary practice.
* Pinyin translation support.
* Study queue and scheduler.
* Database management for HSK words.

## Technologies Used
* **Backend:** Python, Django
* **Frontend:** HTML, CSS, JavaScript
* **Database:** SQLite

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run the server: `python manage.py runserver`
